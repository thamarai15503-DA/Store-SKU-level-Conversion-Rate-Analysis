📊 Conversion Rate Analysis Dashboard
🔍 Project Overview

This project analyzes store-level and SKU-level conversion performance using retail transactional data. The objective is to identify top-performing and underperforming stores and products, track key KPIs, and support data-driven business decisions.

The analysis was performed using Python for data processing and Power BI for interactive dashboard visualization.

🛠️ Tools & Technologies Used

Power BI – Interactive dashboard, KPI cards, slicers, drill-down analysis

Python (Pandas, NumPy) – Data cleaning and feature engineering

Matplotlib / Seaborn – Exploratory data analysis

Excel – Data validation and preprocessing

Kaggle Dataset – Retail store & SKU performance dataset

📂 Project Workflow
1️⃣ Data Cleaning

Removed null and duplicate records

Standardized Store ID and SKU ID formats

Validated revenue and visit values

Ensured consistency in categorical variables

2️⃣ Feature Engineering

Created key performance metrics:

Conversion Rate = (Total Purchases / Total Visits)

Revenue per Store

Revenue per SKU

Performance classification (Top / Underperforming)

Aggregated Store-level and SKU-level KPIs

3️⃣ Exploratory Data Analysis

Distribution of conversion rates across stores

SKU-level performance comparison

Identification of performance gaps

Trend comparison between revenue and visits

📌 Key Insights

Certain stores achieved conversion rates above 63%, indicating strong sales efficiency.

Some stores showed conversion rates below 38%, highlighting improvement opportunities.

SKU performance varied significantly, with top SKUs reaching nearly 59% conversion.

Underperforming SKUs require pricing, marketing, or placement optimization.
